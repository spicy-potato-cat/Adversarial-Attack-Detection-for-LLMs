# Dataset Governance

**Project:** Adversarial Attack Detection for Large Language Models (LLMs)
**Status:** ACTIVE / UNDER INVESTIGATION

## Governance goal

Create a defensible dataset evidence process that preserves raw artifacts, tracks provenance, and prevents unauthorized experimental use while research evidence is still being assembled.

## Core rules

- Raw data is immutable after acquisition and retention review.
- Derived evidence and analyses are separated from the raw layer.
- A dataset or benchmark does not receive a final role without Commander approval.
- Benchmark packaging, public availability, or common usage does not by itself establish quality, safety, or independence.

## Current evidence posture

The repository currently references a broad text and multimodal portfolio, including candidate security benchmarks and attack-material collections. These remain provisional evidence-bearing candidates until the forensic pipeline determines provenance, contamination risk, and legal/ethical review status.

## Status note

The dataset governance model is active and conservative. It does not authorize training or evaluation use of candidate materials.
