# Dataset Registry Summary

**Project:** Adversarial Attack Detection for Large Language Models (LLMs)
**Status:** PROVISIONAL

## Summary

The repository evidence indicates a diverse candidate set spanning text and multimodal datasets, attack benchmarks, and safety-oriented collections. The most relevant clusters include AdvBench, HarmBench, JailbreakBench, XSTest, AutoDAN-related material, GCG-related material, and an overlapping family of public safety benchmarks.

## Registry posture

All registry entries should be treated as stable inventory identifiers only. They do not encode quality, legal status, or scientific trust. A stable ID records a candidate but does not grant an experimental role.

## Notable unresolved cases

- GCG-related/generated material
- AutoDAN-related/generated material
- WASP identity assignment
- FigStep / SafeBench lineage classification
- aggregate benchmark provenance for WildJailbreak and WildGuardMix
- exact release and rights status of several multimodal benchmarks

## Status note

The registry is provisional and under forensic review. Final dataset constitution remains outside the current documentation-only scope.
