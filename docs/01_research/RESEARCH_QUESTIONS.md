# Research Questions

**Project:** Adversarial Attack Detection for Large Language Models (LLMs)
**Status:** ACTIVE

## Primary research question

Can measuring detector disagreement and false agreement improve adversarial-attack detection robustness under realistic false-positive, latency, and verification-cost constraints?

## Secondary questions

- Which detector families produce correlated blind spots on text-based adversarial prompts?
- How often do benign-looking consensus patterns hide false-benign classifications?
- Does disagreement-aware routing improve recall without unacceptable precision loss?
- Can conditional verification reduce attack success without dominating the runtime budget?
- Which dataset and benchmark relationships create contamination risk for conclusions?
- How should the project distinguish between a provisional research insight and a validated contribution?

## Evidence requirement

All answers require precise documentation of data provenance, output quality, overlap structure, and benchmark lineage before they can support a formal conclusion.
