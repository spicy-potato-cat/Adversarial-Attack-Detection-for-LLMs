# Consensus Evasion Plan

**Project:** Adversarial Attack Detection for Large Language Models (LLMs)
**Status:** EXPERIMENTAL / UNDER INVESTIGATION

## Objective

Study whether adversaries can exploit detector agreement patterns, overlap gaps, or consensus calibration to evade a heterogeneous detection system.

## Proposed attack probes

- prompt variations that reduce disagreement across detectors
- adversarial samples designed to preserve a majority benign consensus
- template adaptation that attacks correlated blind spots instead of single-model weaknesses
- prompt perturbations that increase false agreement while remaining semantically similar

## Research posture

This plan is a defensive evaluation design. It does not assume that a consensus-evasion attack has already been discovered or that it is a finalized attack class.

## Reporting requirement

Any consensus-evasion finding must be accompanied by clear provenance, data isolation, and contamination reporting.
