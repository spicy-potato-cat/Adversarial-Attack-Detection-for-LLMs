# Reproducibility

**Project:** Adversarial Attack Detection for Large Language Models (LLMs)
**Status:** UNDER INVESTIGATION

## Reproducibility goal

Make evidence, analysis, and evaluation steps traceable enough for audit and review. This must be true even when the dataset portfolio remains provisional and unresolved.

## Required artifacts

- source or acquisition manifest
- canonical metadata and hash records
- normalizer and transformation script version
- detector configuration and version metadata
- analysis script version and environment context
- evaluation report with uncertainty flags

## Reporting requirement

Every experiment report should specify which artifact versions were used, which dataset entries were included, which provenance records were tracked, and what status flags remain unresolved.

## Status note

This is an active reproducibility standard for the current research stage, not a guarantee that a given evaluation result is final or broadly generalizable.
