# Terminology

## Project identity

**Adversarial Attack Detection for Large Language Models (LLMs)**

This is the official project name. It remains the authoritative title unless the Commander explicitly approves a different name.

## DGAD

**Status:** NON-AUTHORITATIVE WORKING TERM

DGAD — Disagreement-Gated Adaptive Detection — is a temporary shorthand used in architecture discussions for a proposed disagreement-aware adaptive detection approach. This term is not the official project name and has not been formally approved as a final framework name.

Use wording such as:

- "current working architecture concept, informally referred to as DGAD in architecture discussions"
- "a proposed false-agreement-aware detection architecture currently under investigation"
- "the currently proposed architecture investigates..."

Avoid presenting DGAD as a finalized framework or as a replacement project name.

## False agreement

**Status:** PROPOSAL / UNDER INVESTIGATION

The false-agreement concept refers to the current research direction investigating whether correlated detector blind spots and consensus patterns can improve detection robustness. It is not treated as a completed research claim, proven method, or approved framework.

## Core project scope

The project builds adversarial-attack detection and middleware capabilities for LLM applications.

## Current architecture work

The architecture workstream is exploring heterogeneous detection, detector disagreement, false agreement, and conditional verification.
