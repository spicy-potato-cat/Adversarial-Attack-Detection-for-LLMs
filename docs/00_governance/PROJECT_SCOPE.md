# Project Scope

**Project:** Adversarial Attack Detection for Large Language Models (LLMs)
**Status:** UNDER DEVELOPMENT

## Official project identity

The official project name remains:

> Adversarial Attack Detection for Large Language Models (LLMs)

This is the authoritative project identity. The term "DGAD" (Disagreement-Gated Adaptive Detection) is a non-authoritative working concept used during architecture discussions and is not an approved project name or framework name.

The current false-agreement work is an evolving research direction inside the existing project rather than a renamed project or finalized framework.

## Scope of the project

The project develops adversarial-attack detection and middleware capabilities for LLM applications. The work includes dataset qualification, governance, evidence gathering, detection methods, and architecture exploration for robust real-world deployment.

## In-scope documentation work

- Project identity and terminology alignment.
- Research positioning and hypotheses.
- Architecture investigation and design proposals.
- Decision logging for documentation-only governance.
- Current status and open questions.

## Out-of-scope documentation work

- Final approval of dataset experimental roles.
- Forensic or benchmark governance decisions for Phase-3 artifacts.
- Model training, tuning, or evaluation claims.
- Any claim that DGAD is an approved framework name.

## Repository boundary

The documentation workspace under `docs/` is the authorized documentation surface for this agent. The `Dataset/` and `PHASE-3/` directories remain read-only reference material for evidence and forensic review unless the Commander explicitly authorizes a different scope.
