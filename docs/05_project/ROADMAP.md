# Roadmap

**Project:** Adversarial Attack Detection for Large Language Models (LLMs)
**Status:** UNDER DEVELOPMENT

## Phase 1: project documentation and governance

- Lock official project identity and terminology.
- Establish documentation tree and scope boundaries.
- Record research framing and current status.

## Phase 2: data evidence and forensic review

- Inventory candidate datasets and benchmarks.
- Resolve provenance, rights, and lineage evidence.
- Analyze overlap, contamination, and quality signals.

## Phase 3: architecture and hypothesis testing

- Formalize detector contracts and evaluation workflow.
- Evaluate disagreement and false-agreement patterns.
- Measure verification routing under realistic cost constraints.

## Phase 4: evidence-backed recommendation

- Recommend dataset constitution or candidate exclusions only with evidence and approval.
- Refine architecture and operational policies.
- Publish decision-ready documentation for Commander review.

## Current status

The project is currently in the documentation and evidence-building stage. No final benchmark or dataset role is approved.
